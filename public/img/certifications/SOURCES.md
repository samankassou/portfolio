# Certification asset sources

Retrieved 2026-09-05. Original badge artwork is stored locally, without recoloring or cropping. These marks belong to their respective issuers; they are not covered by the Devicon MIT license.

The [homepage](../../../app/page.tsx) displays these badges with the credentials in [certifications.ts](../../../lib/data/certifications.ts). Artwork is not independent verification of credential status or renewal.

## Microsoft

Microsoft Learn's official certification pages were the source for these level badges:

- Expert: [DevOps Engineer](https://learn.microsoft.com/en-us/credentials/certifications/devops-engineer/).
- Associate: [Azure Developer](https://learn.microsoft.com/en-us/credentials/certifications/azure-developer/).
- Associate: [Power BI Data Analyst](https://learn.microsoft.com/en-us/credentials/certifications/power-bi-data-analyst-associate/).
- Fundamentals: [Azure Fundamentals](https://learn.microsoft.com/en-us/credentials/certifications/azure-fundamentals/).

Downloaded from `https://learn.microsoft.com/en-us/media/learn/certification/badges/microsoft-certified-{expert,associate,fundamentals}-badge.svg`.
Local files: [microsoft-expert.svg](microsoft-expert.svg), [microsoft-associate.svg](microsoft-associate.svg), and [microsoft-fundamentals.svg](microsoft-fundamentals.svg).

The exact certification titles remain alongside these generic level badges. No personal verification URLs have been inferred from credential IDs.
