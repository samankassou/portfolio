# Systems in motion

## The audit

The original portfolio has credible Azure modernization, .NET engineering, logistics, and AI work, with authentic recommendations and a complete professional history. The presentation hid that substance inside repeated cards, competing sidebars, and long sections of similar visual weight. The portrait was absent from the main story, case studies looked interchangeable, and the compact hero did little to communicate personality.

## The direction

An engineer's precision with a human point of view. A rotating mathematical knot is the signature: separate paths become a connected system. The message is **“Complexity, made clear.”**

- Graphite, electric lime, and a cool pale light theme. Muted green is secondary, with restrained category colors inside technical diagrams.
- Oversized, tightly spaced grotesk type, an italic serif accent, and monospaced technical labels.
- Open layouts, thin rules, square edges, generous space, numbered chapters. A prominent Azure case study followed by the rest of the work.
- A real portrait and a personal introduction; career details remain accessible through native disclosures.
- Slow, pointer-responsive geometry, restrained entrance animations, and simple hover cues. Native page scrolling, an animation pause button, and reduced-motion support.

## Content integrity

Existing data files remain the source of truth. Azure DevOps and .NET lead; Laravel, AI, and BI add breadth. All five project routes, filters, contact fields and API, languages, qualifications, social links, and recommendations remain available. Diagrams are explicitly conceptual. No invented impact metrics, project screenshots, current credential validity, availability, or graduation claims.

## Implementation

Next.js server-rendered content with small interactive boundaries. The hero is a mathematical 3D knot projected onto Canvas 2D; it needs no added graphics dependency. Rendering is capped around 30 fps with a device pixel ratio cap and visibility/reduced-motion checks. CSS owns the visual system in `app/studio.css`; components are under `app/components/studio/`.

The redesign is implemented in the local project. Existing deployment configuration and contact delivery infrastructure remain intact.
